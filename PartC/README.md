# 36104_AT2Async_Session2_PartC

## Build and deploy a small interactive data app with Streamlit
a Python framework that turns a plain Python script into a web app.

## Work through the official Streamlit tutorial: Create an app.
https://docs.streamlit.io/get-started/tutorials/create-an-app

- Install Streamlit on your own machine with pip install streamlit.
- Follow the tutorial from start to finish. You will load the Uber pickups dataset, cache the download, draw a histogram, put the pickups on a map, and add a slider and a checkbox.
- Deploy the finished app, as covered at the end of the tutorial. Deployment runs through Streamlit Community Cloud and needs your app in a public GitHub repository.
- Open your deployed app in a private browser window to confirm it works for people who are not you.

**Submit the URL of your deployed app as a plain text file through Canvas.**
